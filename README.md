# Currency Exchange App

SPA em React + Vite para converter moedas, ver o histórico de cotações, filtrar dados e exportar CSV, usando a [Frankfurter API](https://api.frankfurter.app).

> Em desenvolvimento por etapas (ver commits).

## Executar
```bash
npm install
npm run dev
```
